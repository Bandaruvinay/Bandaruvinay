## 🚀 Featured Projects

<!-- Replace the repo links below with your actual repository URLs -->

### 1️⃣ Distributed Job Processing Platform
> A scalable, self-hosted task processing platform built to handle **millions of asynchronous background jobs** using a distributed worker architecture.

- ✅ Reliability built in: **Google Cloud Pub/Sub** queues, **exponential backoff** retries and **idempotency keys** to prevent duplicate executions
- ⚡ **Redis** for caching, **PostgreSQL** for state management
- ☁️ Deployed with **Docker** on **Google Cloud Run** for automated horizontal scaling
- 🧰 **Tech Stack:** `Python` `FastAPI` `PostgreSQL` `Redis` `GCP Pub/Sub` `Cloud Run` `Docker`
- 🔗 **GitHub:** [View Repository](https://github.com/Bandaruvinay?tab=repositories)

### 2️⃣ Financial Ledger Processing Engine
> A high-throughput digital wallet backend that guarantees **strict data integrity** for concurrent financial transactions.

- 🔒 **PostgreSQL ACID transactions** and **row-level locking** to prevent race conditions like double-withdrawals
- 📒 **Double-entry ledger** with the **transactional outbox pattern** for reliable event publication, even during partial failures
- 🧰 **Tech Stack:** `Python` `FastAPI` `PostgreSQL` `SQLAlchemy` `Docker`
- 🔗 **GitHub:** [View Repository](https://github.com/Bandaruvinay?tab=repositories)

### 3️⃣ Enterprise LMS Plugins & Integrations (Moodle & Totara)
> Custom plugins, extensions and RESTful API integrations developed professionally at Human Logic to meet complex client requirements.

- 🔄 Improved data synchronization across services and platform reliability
- 🗄️ Optimized database queries and supported low-downtime deployments of LMS updates
- 🧰 **Tech Stack:** `PHP` `Moodle` `Totara` `REST APIs` `SQL`
